Each source PR includes `docs/showcase.md` with reproduction details. Mermaid definitions are in `docs/showcase.mmd`; exported SVGs use native SVG text. VRI uses its Vulkan path tracer at 128 samples. VRI-Framework uses offline Gaussian splat rendering at 1280×720. WQX shows the complete 320×160 browser LCD, enlarged by an integer factor. Bixuetang uses an empty local SQLite database with a demo learner. Online Tools uses four self-made images.
