![Portfolio-98's desktop and About Me window.](/assets/img/projects/portfolio-98.png)

Portfolio-98 is a playful alternative view of my portfolio, built with Next.js. On desktop it presents draggable and resizable windows, a taskbar and a Start menu. On phones it switches to a Pocket PC / PDA-style shell with full-screen applications.

## A portfolio as a desktop

Markdown files supply the CV, projects, publications and posts. An application registry connects these to desktop windows and mobile launchers. Other applications include a virtual filesystem, an MS-DOS-style prompt, Minesweeper and a music player. [Lazy-100](/projects/lazy_100/) runs inside a game window.

## Interface and credits

The interface includes configurable wallpapers, screensavers, GLSL backgrounds and small period-inspired easter eggs. The cover was captured from the [live browser demo](https://zzxzzk115.github.io/portfolio-98/).

The project uses 98.css for its widget styling and Strudel for live-coded music. Source and credits are available in the [AGPL-3.0 repository](https://github.com/zzxzzk115/portfolio-98).
